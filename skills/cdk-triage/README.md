# CDK triage skills

Skills for triaging AWS CDK GitHub issues, with any agent.

| Skill | Triages |
|---|---|
| [`cdk-issue-triage`](./cdk-issue-triage/SKILL.md) | One issue in `aws/aws-cdk` or `aws/aws-cdk-cli`: context, source, docs, reproduction and a triage report with a proposed response and labels |
